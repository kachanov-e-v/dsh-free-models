# Roadmap

## 0.1.0 — текущая версия

- [x] Live-каталоги OpenRouter, Kilo, Vercel.
- [x] models.dev метаданные.
- [x] Курируемый free-tier реестр.
- [x] Settings → Бесплатные модели: фильтры, карточки, evidence, deep search.
- [x] `free_models_search`, `free_models_config`.
- [x] Add/merge в `llm-pi-ai` через settings revision-CAS.
- [x] Сохранение ключа в DSH credentials.
- [x] Тестовый запрос и discovery моделей.
- [x] Тесты и документация.

## 0.2.0 — устойчивость и охват

- [ ] Дисковый кэш каталога между перезапусками (через storage domain).
- [ ] ETag/If-None-Match для live-источников.
- [ ] Больше источников: Cerebras API catalog, Together, Fireworks, SambaNova,
      Hyperbolic, OVHcloud, Infomaniak (после проверки).
- [ ] Отдельная категория «free tier только для части моделей».
- [ ] Проверка free-tier страниц через `ctx.web.fetch` и ручное подтверждение.
- [ ] Экспорт всего каталога в JSON/YAML.

## 0.3.0 — управление провайдерами

- [ ] Редактирование существующего профиля (endpoint, env, модели) из плагина.
- [ ] Удаление добавленного маршрута и связанного ключа.
- [ ] OAuth/sign-in там, где провайдер это поддерживает.
- [ ] Проверка нескольких моделей пакетом (с явным предупреждением о квоте).
- [ ] История тестов и last-checked статус в карточке.

## Идеи без обещания

- Автоматическое обнаружение новых провайдеров из веб-поиска с ручным
  подтверждением.
- Сравнение стоимости/контекста между провайдерами.
- Уведомления об изменении free tier.

## Non-goals

- Обход лимитов, ToS или платёжных требований провайдеров.
- Автоматическая отправка inference-запросов без действия пользователя.
- Хранение ключей в конфиге или исходниках.
- Автоматическое доверие произвольным страницам из интернета.
- Поддержка embeddings/image/audio моделей в каталоге.
